# Security policy

This policy applies to every jacksonlin-infra repository that does not have its own `SECURITY.md`.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub: **Security → Report a vulnerability** on the affected repository.

Include the project and version, what an attacker can do, and the steps to reproduce. We aim to reply within a week. Once a fix is released, the advisory is published with credit to you unless you prefer otherwise.

## Supported versions

Unless a repository says otherwise, only its latest release receives fixes.
