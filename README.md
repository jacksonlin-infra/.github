# jacksonlin-infra/.github

Organization-wide files for [jacksonlin-infra](https://github.com/jacksonlin-infra):

- `profile/README.md`: the organization profile page.
- `SECURITY.md`: default security policy for repositories without their own.
- `brand/`: the organization avatar (`avatar.svg` is the source; PNGs at 512 and 1024 px).
